## `OPT-68-ENGINEERING` evaluator

**Primary evidence:** design brief, requirements trace, options matrix, analysis / test plan, data interpretation, safety / ethics review, communication, handoff, postmortem.

**Dimensions:** requirements; problem framing; alternatives; technical evidence; testing; uncertainty; safety / welfare; ethics; communication / teamwork; improvement.

**Critical failures:** unsafe shortcut, missing discipline-specific standard, simulation presented as validation, or agent output presented as sign-off.

**Challenge set design:** conflicting requirements; missing safety constraint; test result with uncertainty; design alternative tradeoff; team handoff loss; discipline-scope mismatch.

**Improvement loop:** diagnose requirements or safety gap → revise design-review checklist → rerun on a new design problem → qualified reviewer checks technical and safety adequacy.
